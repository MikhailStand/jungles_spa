# Jungle Spa

Одностраничный статический сайт салона Jungle Spa. В каталоге 29 услуг с текстовыми описаниями, составом, длительностью и ценами.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

## Production-сборка

```bash
pnpm build
```

Готовые статические файлы появляются в `dist/client`.

## GitHub Pages

В репозитории уже есть workflow `.github/workflows/pages.yml`. После загрузки проекта в GitHub:

1. Откройте `Settings → Pages`.
2. В поле `Source` выберите `GitHub Actions`.
3. Отправьте изменения в ветку `main`.

Workflow сам определит имя репозитория, настроит базовый путь, соберёт сайт и опубликует содержимое `site/dist/client`.

Если папка `site` станет корнем отдельного репозитория, перенесите `.github` из родительской папки в этот репозиторий и замените `working-directory: site` на `working-directory: .`.

## Перенос в Tilda

Страница разбита на независимые секции: первый экран, вступление, два формата ритуалов, популярные услуги, полный каталог, сертификаты, мастера, абонементы, отзывы и контакты. Все тексты и цены находятся в `app/page.tsx`, а стили — в `app/globals.css`; эту структуру можно повторить блоками в Tilda.

Перед публичным запуском подтвердите у салона цены, график работы, правила сертификатов и скидку по абонементам для программ на двоих.
